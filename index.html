50 elements

A calm, airy component library

Extracted from the dashboard UI: white surfaces on a near-white canvas, 8px radii, soft 2px borders that turn indigo on interaction, and a single 0.15s ease. Every page below is a standalone HTML file that links the shared css/main.css and js/script.js.
