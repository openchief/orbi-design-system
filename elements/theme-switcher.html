Theme switcher

Switches the whole interface between light and dark. The choice is saved in the browser, and “System” follows the operating system setting. Try it on this page.

Icon toggle

Segmented

Setup

<!-- in <head>, after the stylesheet, so the theme is set before first paint -->
<link rel="stylesheet" href="css/main.css">
<script src="js/theme.js"></script>

// from script
OrbiTheme.set("dark");            // "light" | "dark" | "system"
document.addEventListener("themechange", function (e) { console.log(e.detail.theme); });
