Calendar

A schedule with separate day, week, month and year views. Click an empty slot or use Add event to create an item, and click any event to edit or delete it.

Week view

Usage

<div class="event-calendar" data-calendar data-view="week"
     data-events='[{"title":"Standup","date":"2026-10-09","start":"09:00","end":"09:30","color":"blue"},
                   {"title":"Holiday","date":"2026-10-12","allDay":true,"color":"green"}]'></div>

// read or change items from script
var cal = OrbiCalendar.get(document.querySelector("[data-calendar]"));
cal.addEvent({ title: "Review", date: "2026-10-10", start: "14:00", end: "15:00", color: "purple" });
el.addEventListener("calendar:change", function (e) { console.log(e.detail.events); });
